# 植物大战僵尸 · 极简版

零依赖的网页版植物大战僵尸，单文件 HTML + Canvas 实现，双击 `index.html` 即可游玩。

![tech](https://img.shields.io/badge/tech-HTML5%20Canvas-green) ![deps](https://img.shields.io/badge/dependencies-none-success)

## 玩法

点击顶部卡片选择植物，再点击草坪种下；点击天上掉落或向日葵产生的阳光收集资源。撑过最终大波僵尸即获胜，每行有一台小推车作为最后防线。

| 快捷键 | 功能 |
|--------|------|
| `1` – `5` | 快速选择植物卡片 |
| `Esc` | 取消选择 |

## 植物

| 植物 | 费用 | 能力 |
|------|------|------|
| 🌻 向日葵 | 50 | 定期产生阳光 |
| 🌱 豌豆射手 | 100 | 自动射击本行僵尸 |
| ❄️ 寒冰射手 | 175 | 豌豆附带 3 秒减速 |
| 🥜 坚果墙 | 50 | 高血肉盾（600 HP），受损会裂开 |
| 🍒 樱桃炸弹 | 150 | 3×3 范围高额爆炸伤害 |

## 僵尸

- **普通僵尸** — 基础敌人
- **路障僵尸** — 270 HP
- **铁桶僵尸** — 560 HP，随波次增强出现

## 运行

无需构建、无需服务器，三选一：

- **Windows**：双击 `启动游戏.bat`（自动用默认浏览器打开）
- 任意系统：直接双击 `index.html`
- 或起一个本地静态服务器：`npx serve .`

## 技术说明

- 纯原生 JavaScript，游戏逻辑与 Canvas 绘制均在 `index.html` 内
- 音效由 WebAudio 实时合成，无外部资源
- 固定时间步长的 `requestAnimationFrame` 主循环
